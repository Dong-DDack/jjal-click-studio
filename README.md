## ✦ 내 취향으로 만드는 한 장

| 이미지 카드 | 문구 디자인 | 움직이는 짤 |
| --- | --- | --- |
| PNG·JPG·JPEG 배경과 배경색 | 한글·영문 글꼴 24종 | GIF·MP4·WebM·MOV 불러오기 |
| 1:1 · 4:5 · 9:16 · 직접 크기 설정 | 크기·색·투명도·정렬·기울임·그림자 | 동영상 최대 5초 구간 선택 |
| PNG 또는 용량 절약 JPG 저장 | 드래그 이동·모서리 회전·문구 영역 조절 | 문구·스티커를 합성한 GIF 저장 |

- **스티커 90종** — 하트·반짝임 / 자연·날씨 / 동물 / 음식·카페 / 소품·취미 / 표정·손짓
- **바로 편집** — 문구 더블클릭, 입력창 자동 확장, 독립된 항목 선택·복제·삭제
- **작업 되돌리기** — 실행 취소·다시 적용, 최대 40단계(메모리 제한에 따라 감소)
- **나만의 템플릿** — 생성·불러오기·덮어쓰기·삭제, 브라우저에 보관, JSON 백업·복원
- **작업 보호** — 지원하지 않는 파일 거부, 오류 시 기존 작업 유지, 저장 전 잘림 확인

## 🚀 세 번이면 완성

1. **불러오기** — 이미지·GIF·동영상을 올리거나 배경색을 고릅니다.
2. **꾸미기** — 문구·스티커를 추가하고 위치와 스타일을 조절합니다.
3. **내려받기** — PNG/JPG로 카드를 저장하거나 GIF로 움직임을 저장합니다.

우측 **문구·스티커 옆 `+`**에서도 추가할 수 있습니다. 항목이 많아지면 목록 안에서 스크롤합니다.

문구 선택 중 정렬 단축키는 브라우저 기본 동작 대신 편집기에 적용됩니다.

## 🎞️ 지원 형식과 저장

| 구분 | 지원과 제한 |
| --- | --- |
| 정지 이미지 | PNG·JPG·JPEG, 최대 15MB / 2,400만 픽셀 |
| GIF 입력 | 최대 15MB, 최대 5초와 프레임 메모리 제한 적용 |
| 동영상 입력 | MP4·WebM·MOV, 최대 100MB. 브라우저가 해당 코덱을 지원해야 합니다. |
| 정지 이미지 저장 | 기본 PNG. JPG 선택 시 품질 90%의 손실 압축 |
| GIF 저장 | 긴 변 최대 **480px**, 최대 **8fps·5초**, 무음. 배치를 비례 축소 |
| GIF 처리 | 별도 Worker에서 한 장씩 처리. 진행 표시·취소·시간 제한 |

GIF는 프레임별 적응형 256색 팔레트와 LZW 압축을 사용합니다. 색·움직임이 원본과 완전히 같지는 않으며 용량 절약 효과는 이미지에 따라 달라집니다. JPG도 모든 이미지에서 PNG보다 작지는 않습니다.

GIF 불러오기는 `ImageDecoder`를 지원하는 최신 Chrome·Edge를 권장합니다. 일부 브라우저에서는 지원되지 않습니다. GIF 저장에는 Web Worker가 필요합니다.

## 💾 템플릿과 파일 보호

- 템플릿은 **현재 기기·브라우저의 IndexedDB**에 저장됩니다. 새로고침 후 유지되지만 브라우저 데이터 삭제 시 사라집니다.
- JSON은 전체 검증 후 기존 목록을 교체합니다. 잘못된 JSON은 저장 전에 거부합니다.
- 새 GIF·동영상 템플릿에는 **원본 파일과 선택 구간**을 저장합니다. JSON v2에도 원본을 포함하여 다른 브라우저에서 움직임을 복원할 수 있습니다.
- **이전 JSON v1의 정지 화면에는 원본이 없습니다.** 원본 GIF·영상을 다시 올려 템플릿을 덮어쓴 뒤 새 JSON을 내보내야 합니다.
- 원본을 포함하므로 JSON 용량은 커집니다. 내보내기는 미디어·배경 합계 약 80MB 이하, 가져오기는 JSON 120MB 이하로 제한합니다.
- 미디어 백업 JSON에는 원본 파일이 포함됩니다. 원본에 있던 메타데이터도 보존되므로 공개 제출용 완성 이미지와 구분해 보관해 주세요.
- 이 앱은 업로드한 미디어를 서버로 전송하지 않습니다. 처리와 변환은 브라우저 안에서 수행됩니다.
- 정지 배경은 캔버스로 재인코딩하여 원본 EXIF/GPS 메타데이터를 복사하지 않습니다. 이미지 자체와 문구의 개인정보는 사용자가 확인해야 합니다.
- 업로드 파일의 사용 권한은 사용자가 확인해야 합니다. 기본 화면은 코드로 만든 배경과 문구입니다.
- 글꼴은 시스템 글꼴입니다. 미설치 글꼴과 한글 미지원 영문 글꼴은 대체될 수 있습니다.

## 🛠️ 로컬 실행

빌드·패키지 설치·로그인·API 키가 필요 없습니다. `index.html`을 브라우저에서 열면 사용할 수 있습니다. 파일 URL에서 Worker가 차단되면 로컬 서버를 사용하세요.

```sh
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.

```text
index.html          편집 화면
style.css           네이비·블루 테마와 반응형 레이아웃
app.js              캔버스 편집·템플릿·파일 검사
history.js          실행 취소·다시 적용
template-media.js   IndexedDB·원본 미디어 템플릿·JSON v2
media.js            GIF·동영상 재생과 구간 추출
gif-encoder.js      적응형 팔레트·GIF 인코더
gif-worker.js       별도 작업 스레드
tests/              자동 회귀 검사
docs/               개발 기록
```

## ✅ 짧은 확인 방법

**위치** — [딸깍 편집기](https://dong-ddack.github.io/jjal-click-studio/)로 이동합니다.  
**행동** — PNG/JPEG 올리기 → 문구 수정하기 → 내려받기를 누릅니다.  
**통과 모습** — 미리보기에 문구가 반영되고 같은 배치로 저장됩니다. 영역 밖 문구는 저장 전 확인창이 표시됩니다.  
**안 될 때 모습** — 오류 이유가 표시되며, 미지원 파일·잘못된 JSON은 기존 작업·목록을 유지합니다.

## 🧪 자동 검사

Node.js가 설치되어 있다면 다음 명령으로 검사합니다.

```sh
node tests/history.cjs
node tests/gif-export.cjs
node tests/template-media.cjs
```

편집·단축키·실행 취소, 파일 거부, 잘림 안내 분기, GIF 독립 복호화, 실제 별도 스레드 인코딩, 취소·오류 복구를 검사합니다. DOM·동영상 탐색은 일부 모의 객체를 사용하므로 **실제 브라우저 동작을 모두 보증하지 않습니다.**

과제용 극단 입력 12건 검사표, 세 화면비 실제 대조, 템플릿 새로고침 검사, 완성 이미지 3개와 권한·공개 안전 검사는 별도 증빙이 필요합니다. 전체 채점 항목 통과를 주장하는 최종 보고서는 아닙니다.
