# 고정 검사표: 동영상 → GIF 저장과 편집 복구

이 검사표는 AI A와 AI B가 같은 조건에서 사용할 사용자 관점 검사 10개다. 첫 AI 작업을 시작하기 전에 고정하며, 이후 ID·입력·행동·기대값을 바꾸거나 삭제·완화하지 않는다. 실행 결과는 저장소 루트의 `HANDOFF.md`에만 기록한다.

## 공통 조건

- **기능:** 동영상의 선택 구간을 GIF로 저장하고, 진행 표시·취소·오류 뒤 편집을 이어갈 수 있는지 확인한다.
- **정상 입력:** `tests/fixtures/private-input.mp4`는 개인 영상이므로 `.gitignore` 처리되어 Git에 추가하지 않는다. A와 B는 같은 로컬 파일을 별도 제공받아 사용한다. 크기 3,144,109 bytes, SHA-256 `82B832B3A7593526FCB70CCA8BFD7D3B76314688499B7433D62AE3632DA3236E`.
- **오류 입력:** 저장소에 포함된 `tests/fixtures/invalid-media.mp4`. 테스트용으로 의도적으로 재생 불가능한 짧은 파일이며 크기 71 bytes, SHA-256 `C13F852C8F794B1B361ACFF73D46E4263F92E6036BCDDF526003253B0719777E`다.
- **구간:** 시작 1.0초, 길이 3.0초, 끝 4.0초.
- **브라우저:** 실제 headed Chrome 한 가지를 A와 B가 공통 사용한다. 전체 버전을 HANDOFF에 기록한다.
- **실행 주소:** 저장소 루트에서 `python -m http.server 8080 --bind 127.0.0.1` 실행 후 `http://127.0.0.1:8080/`을 연다. `file://` 주소를 사용하지 않는다.
- **순서:** G01→G07은 같은 편집기에서 실행한다. G08에서 오류 입력을 시도한 뒤 G09 편집 복구, G10 정상 입력으로 재저장한다. 페이지를 새로고침하지 않는다.
- **판정:** 실제 사용자 화면·다운로드를 확인한다. 상태 문구만으로 GIF 저장 PASS를 판정하지 않는다. 파일 확장자가 `.gif`인지 확인한다. 실행하지 않은 항목은 미실행으로 둔다.
- **공통 상한:** AI별 작업 시간 최대 45분, 사용자 요청 최대 12회. 무료 한도 소진을 시도하지 않는다.

## 검사 10개

| ID | 사용자 입력 또는 행동 | 관찰 가능한 기대값 |
|---|---|---|
| T05-G01 | 정상 입력 MP4를 불러온다. | 영상이 편집 배경에 표시되고 재생 및 GIF 저장이 가능하며 앱이 응답한다. |
| T05-G02 | 시작 1초, 길이 3초를 설정하고 적용한다. | 1.0~4.0초, 3초 구간이 화면에 표시되고 미리보기에서 해당 구간을 사용한다. |
| T05-G03 | 선택 구간으로 GIF 저장을 시작한다. | 변환 중 진행 표시와 취소 컨트롤이 보인다. |
| T05-G04 | 변환 완료까지 기다린다. | 진행 표시가 닫히고 실제 `.gif` 파일이 다운로드된다. |
| T05-G05 | 같은 입력과 구간으로 GIF 저장을 다시 시작한 뒤 취소한다. | 변환이 취소되고 진행 표시가 닫히며 앱이 응답 가능한 상태로 돌아온다. |
| T05-G06 | G05 취소 직후 새 문구를 추가하고 캔버스에서 이동한다. | 문구가 하나 추가되고 위치 이동이 화면에 반영된다. |
| T05-G07 | 취소 뒤 같은 구간으로 GIF 저장을 재시도한다. | 변환이 정상 완료되고 실제 `.gif` 파일이 다운로드된다. |
| T05-G08 | 정상 영상이 불러와진 상태에서 오류 입력 `invalid-media.mp4`를 불러온다. | 재생 불가/지원하지 않는 파일 오류가 사용자에게 표시되고 앱이 응답한다. 기존 정상 영상과 편집 내용은 유지된다. |
| T05-G09 | G08 오류 뒤 같은 편집기에서 새 문구를 추가하고 이동한다. | 오류 뒤에도 기존 영상·편집 내용이 유지되고 문구 추가 및 이동이 가능하다. |
| T05-G10 | 기존 정상 영상의 같은 구간으로 GIF 저장을 다시 시도한다. | 오류 입력 후에도 변환이 정상 완료되고 실제 `.gif` 파일이 다운로드된다. |

## 기준 변경 기록

- AI 작업 시작 전 기준을 이 커밋의 전체 SHA로 고정한다.
- 검사 ID 삭제 0건, 기대값 완화 0건이어야 한다.
- 결과 기록 양식은 두지 않는다. AI A/B 관찰 결과는 `HANDOFF.md`에 기록한다.
