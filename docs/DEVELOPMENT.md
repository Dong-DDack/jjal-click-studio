# 딸깍 — 짤·카드 스튜디오 / 프로토타입 03

`index.html`을 브라우저에서 열면 사용할 수 있는 정적 웹 편집기입니다. 외부 서비스·로그인·API 키 없이 동작합니다.

## 사용하기

1. PNG/JPEG를 올리거나 배경 색을 고릅니다.
2. 새 문구를 추가하고 캔버스에서 드래그합니다. 오른쪽에서 글꼴·크기·색·투명도·회전·정렬을 바꿉니다.
3. 비율을 고른 뒤 이미지를 내려받습니다. 스페이스바를 누르는 동안 선택 테두리 없는 확대 미리보기가 나타납니다. 모바일에서는 크게 보기 버튼을 누르세요.

방향키로 위치를 세밀하게 조정할 수 있으며 Shift를 함께 누르면 더 크게 움직입니다. 글을 입력하는 중에는 스페이스바가 정상적으로 공백을 입력합니다.

## 포함된 기능

- 독립된 문구 스티커, 복제·삭제·맨 앞으로 이동
- 5가지 시스템 글꼴 스타일, 색상·불투명도·회전·정렬
- 1:1 / 4:5 / 9:16, 동일 캔버스를 이용한 미리보기와 PNG 저장
- PNG/JPEG 형식·15MB·2,400만 픽셀 제한, 잘못된 파일 거부 시 기존 작업 유지
- 브라우저 localStorage의 템플릿 생성·불러오기·수정·삭제
- 템플릿 JSON 내보내기·전체 검증 후 복원, 오류 시 기존 목록 유지
- 입력 이미지 캔버스 재인코딩으로 원본 메타데이터 제외

## 초안의 한계

글꼴은 기기에 설치된 시스템 글꼴에 따라 대체될 수 있습니다. 전용 한글 웹폰트는 아직 포함하지 않았습니다. 투명도 슬라이더 100%는 완전히 보임, 0%는 완전히 투명함을 뜻합니다. 템플릿은 현재 브라우저에 저장되며 저장 공간 제한을 초과하면 오류를 안내합니다. JSON 가져오기는 기존 목록을 가져온 목록으로 교체합니다.

기본 카드는 코드로 구성한 단색 배경과 문구로 외부 이미지가 없습니다. 업로드 이미지의 권한은 사용자가 확인해야 합니다. 공개 배포와 과제 전체 12건 검사 및 FAIL→PASS 증빙은 후속 작업입니다. 이 초안이 과제의 모든 통과 기준을 검증한 최종 제출물은 아닙니다.

## 추가 조작

- 꾸미기 스티커 10종을 클릭해 추가할 수 있습니다. 이모지 모양은 운영체제에 따라 다를 수 있습니다.
- 선택한 문구·스티커는 Delete 키로 삭제합니다. 입력칸에서 글을 쓰는 중에는 항목을 삭제하지 않습니다.
- 모서리의 초록 원을 드래그하면 회전합니다.
- 변 가운데의 흰 사각형을 드래그하면 문구 입력 영역을 조절합니다. 글자 크기는 유지되며 가로 폭에 따라 줄바꿈과 정렬이 바뀝니다. 세로 영역은 내용 높이보다 작아지지 않아 글씨가 잘리지 않습니다. 그림 스티커는 기존처럼 크기가 바뀝니다.
- 변경한 크기·회전·스티커는 템플릿과 JSON에 함께 저장됩니다.
- Node 모의 캔버스 검사: 선택, 변 손잡이 크기 조절, 모서리 회전, JSON 왕복, Delete 삭제, 입력 중 삭제 방지 통과. 실제 브라우저 시각 검증은 별도입니다.

문구 더블클릭: 캔버스에서 직접 입력합니다. 바깥 클릭 또는 Ctrl+Enter로 완료, Esc로 취소, Enter로 줄바꿈합니다.

## 정렬 단축키 · 직접 크기 · 스티커 카테고리

- 문구 선택 후 Ctrl+L은 왼쪽, Ctrl+E는 가운데, Ctrl+R은 오른쪽 정렬입니다. 문구 입력 중에도 동작합니다. 문구가 선택된 동안 해당 브라우저 기본 단축키 대신 편집기 정렬이 적용됩니다.
- 직접 설정의 가로·세로를 입력하고 적용합니다. 각 변 100~4096px, 전체 1,200만 픽셀 이하입니다. 잘못된 크기는 기존 작업을 유지하며 거부합니다. 출력 이미지와 템플릿·JSON에도 같은 크기를 사용합니다.
- 스티커는 하트·반짝임, 자연·날씨, 동물, 음식·카페, 소품·취미, 표정·손짓의 6개 카테고리, 총 90종입니다.

## GIF · 동영상

GIF(15MB 이하), MP4/WebM/MOV(100MB 이하)를 배경으로 올릴 수 있습니다. 동영상은 브라우저에서 디코딩 가능한 코덱만 지원합니다. GIF는 ImageDecoder를 제공하는 Chrome/Edge가 필요하며 최대 5초, 프레임 메모리 제한을 적용합니다.

동영상의 시작 지점과 0.1~5초 길이를 지정하고 구간 적용을 누릅니다. 끝에 도달하면 선택 구간을 반복합니다. 상단 내려받기는 배경 형식에 따라 정적 이미지 → PNG, GIF → GIF, 동영상 → GIF로 저장합니다. 모든 형식에 편집한 문구·스티커가 합성됩니다. 미디어 패널의 저장 버튼도 동일하게 동작합니다. 영상 저장은 약 420만 픽셀 이하 캔버스를 지원합니다. 동영상은 선택 구간의 시점을 순서대로 탐색하여 GIF 프레임으로 합성합니다. 실시간 녹화 API는 사용하지 않습니다.

템플릿·JSON에는 움직이는 원본 대신 재인코딩한 정지 배경을 저장합니다. 움직임을 복원하려면 미디어를 다시 업로드해야 합니다. 원본 미디어는 서버에 업로드되지 않습니다. 이 업로드 파일은 사용자 본인의 사용 권한 확인이 필요합니다.

기술 참고: https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/captureStream 및 https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder/isTypeSupported_static

## 사이트 색상

주요 색상 rgb(15, 53, 97), 강조 색상 rgb(30, 100, 212). 밝은 블루 배경과 테두리를 사용합니다. 사이트 로고는 짤 아이콘 + 딸깍입니다. 캔버스의 사용자 작업 색상은 사이트 테마와 독립적으로 유지합니다.

## GIF 형식 저장 수정

GIF89a 파일을 브라우저에서 직접 생성합니다. 원래 캔버스 크기와 최대 5초 재생 시간을 유지하며 반복 재생합니다. 프레임별 적응형 256색 팔레트와 최대 초당 15프레임을 사용하므로 색상과 부드러움은 원본과 다를 수 있습니다. 큰 캔버스는 총 8천만 프레임 픽셀 작업량에 맞춰 프레임 수를 낮춥니다. GIF·동영상 저장은 캔버스 약 420만 픽셀 이하입니다. GIF는 압축률이 낮아 파일 크기가 클 수 있습니다.

검증: GIF89a 헤더·크기·3개 프레임의 LZW 독립 복호화·팔레트 픽셀·프레임 지연 시간·반복 확장 통과. JS 문법 검사 통과. 실제 브라우저 다운로드와 동영상 인코딩 재생 검증은 별도입니다.

## 동영상 GIF 통합 및 화질 개선

상단·미디어 패널의 내려받기는 움직이는 GIF와 동영상 모두 GIF로 저장합니다. 동영상 선택 구간을 정지 탐색하여 프레임을 추출하며 저장 후 원래 재생 위치와 재생 여부를 복원합니다. 진행 상태와 탐색 시간 초과 오류를 표시하며 실패 시 편집 잠금을 해제합니다.

고정 RGB332 팔레트를 프레임별 가중 중앙값 분할(median-cut) 적응형 팔레트로 교체했습니다. GIF 256색 한계로 원본과 완전히 같은 색을 보장하지는 않습니다. GIF 압축률과 큰 파일 크기는 후속 개선 사항입니다.

검사: node tests/gif-export.cjs — GIF 독립 LZW 복호화, 로컬 팔레트, 크기·지연·반복, 동영상 구간 탐색·GIF 확장자·위치 복원·오류 후 편집 복원 통과. 합성 그라데이션에서 이전 방식 대비 색상 제곱 오차 99% 감소(이 테스트 이미지에만 해당). 실제 브라우저의 사용자 동영상 재생·다운로드는 미검증입니다.

## GIF 변환 안정성 수정 (현재 동작)

이 항목이 앞선 GIF 출력 크기·프레임 설정 설명보다 우선합니다. GIF·동영상 모두 긴 변 최대 480px, 초당 최대 8프레임, 최대 40프레임/5초로 출력합니다. 원래 편집 좌표와 글자 크기를 비례 축소하며 캔버스 편집 크기는 저장 후 복원합니다.

색상 계산과 GIF 조립은 Blob Web Worker에서 처리하며 프레임을 한 장씩 전송하고 응답을 받은 뒤 다음 장면을 처리합니다. 변환 중 전체 크기 미리보기 루프를 중지하여 중복 그리기와 PNG 생성 부하를 없앴습니다. 진행 창, 취소 버튼/Esc, 작업 60초 제한, Worker 응답 10초 제한을 적용합니다. 디코더가 멈춰도 취소 후 편집 화면 복구를 기다리게 하지 않습니다. Worker 실행이 차단된 환경에서는 오류를 표시하며 메인 스레드 변환으로 대체하지 않습니다.

검증: node tests/gif-export.cjs. 실제 Node 별도 스레드에서 480×270 프레임 40장 변환(테스트 패턴 약 5.6MB), 전송 후 원본 버퍼 해제, GIF 독립 복호화·적응형 팔레트 검사, 선택 구간 탐색, 실패/취소 후 UI·재생 위치 복원, 4096px 캔버스의 480px 출력 제한 통과. 브라우저 실영상 디코더·장치별 메모리 상황은 이 검사에 포함되지 않습니다.

## 글꼴과 실행 취소

글꼴을 24종으로 확장하여 한글·기본, 영문 산세리프, 영문 세리프, 영문 스크립트/모노 그룹으로 제공합니다. 시스템 글꼴이며 미설치 글꼴은 대체됩니다.

Ctrl+Z 실행 취소, Ctrl+Y 다시 적용입니다. Ctrl+L 왼쪽, Ctrl+E 가운데, Ctrl+R 오른쪽 정렬을 유지합니다. 상단 실행 취소/다시 적용 버튼도 사용할 수 있습니다. 문구·스티커 추가·삭제·스타일·위치·영역·회전·캔버스 크기/배경 색 변경을 최대 40단계까지 저장합니다(메모리 제한에 따라 감소). 새 이미지·GIF·동영상 업로드나 배경 미디어 변경은 새 이력의 시작입니다. 템플릿 목록 CRUD는 이력 대상에서 제외됩니다. PROTOTYPE 03 표시는 제거했습니다.

## 실행 취소 및 긴 문구 입력 수정

전역 키 입력에서 historyShortcut 호출이 누락된 결함을 수정했습니다. 이동·회전·크기 변경은 포인터 작업 종료 시 즉시 기록하고, 슬라이더·색상·글꼴에 포커스가 있어도 Ctrl+Z/Y가 동작합니다. 기존 함수 단위 검사에 더해 실제 등록 keydown, pointermove/up, input 처리기를 호출하는 회귀 검사를 추가했습니다.

우측 문구 입력창은 scrollHeight에 맞게 높이가 자동 증가합니다. 캔버스 직접 편집창은 최대 화면 높이의 70%까지 증가하고 이후 내부 스크롤을 허용합니다. 내부 스크롤 때문에 편집창이 닫히던 처리를 제거했습니다. 같은 값을 입력창에 반복 대입하지 않아 커서와 한글 조합을 방해하지 않게 했습니다. 글자 수 제한은 기존 2,000자에서 20,000자로 확장했습니다. 캔버스 범위를 넘어가는 문구는 여전히 이미지 영역 밖에서 잘리므로 글씨 크기·폭·위치를 조절해야 합니다.

검증: 실제 등록 이벤트 경로로 문구 입력·드래그 이동·회전 슬라이더의 Ctrl+Z/Y, 3,000자 직접 입력·내부 스크롤 후 편집 유지·자동 높이 검사 통과. 실제 브라우저 IME 조합 동작은 별도 확인이 필요합니다.

## 입력창 표시 및 Enter 규칙

캔버스 입력창이 편집 시작 당시의 좁은 폭에 고정되어 마지막 글자만 보이던 문제를 수정했습니다. 입력할 때 현재 문구의 폭을 다시 계산해 입력창을 확장하고 불필요한 가로 스크롤을 초기화합니다. 사용자가 지정한 문구 영역 폭은 유지하며 그 경우 줄바꿈에 맞춰 높이가 늘어납니다. Enter는 완료, Shift+Enter는 줄바꿈, Esc는 취소입니다. 우측 문구 입력창도 Enter 완료/Shift+Enter 줄바꿈 규칙을 사용합니다. 한글 조합 중 Enter와 keyCode 229는 완료 처리를 하지 않습니다.

## 파일 검증・잘림 안내·용량 절약

배경 업로드는 PNG/JPG/JPEG/GIF/MP4/WebM/MOV의 확장자와 파일 앞부분 시그니처를 대조하고 실제 디코딩까지 성공해야 교체합니다. 문서·실행파일·위장된 형식은 오류를 안내하고 작업을 유지합니다. JSON은 별도 템플릿 가져오기에서만 처리합니다.

PNG/JPG/GIF 저장 전 회전·스티커 크기를 반영한 콘텐츠 경계로 잘림을 검사하여 취소하고 수정/그대로 내려받기 모달을 표시합니다. 빈 문구와 완전 투명 항목은 제외합니다. 경계 검사는 텍스트 레이아웃 영역 기준으로 보수적으로 계산합니다.

정지 이미지는 기본 PNG(선명도 유지), 선택 시 JPG 품질 90%(손실 압축)를 저장합니다. 실제 이미지 종류에 따라 JPG가 항상 더 작지는 않습니다. GIF는 동일 적응형 팔레트와 프레임을 유지하면서 LZW 반복 문자열 압축을 적용했습니다. 단색 480×270 테스트 프레임에서 이전 약 146KB 대비 약 2KB, 약 99% 감소했으며 사진·노이즈 영상은 감소 폭이 작습니다. 프레임 크기/재생 길이 검사는 tests/gif-export.cjs, 거부·작업 유지·회전 잘림·저장 취소/진행 검사는 tests/history.cjs에 있습니다. 실제 브라우저 모달·다운로드 QA는 별도입니다.

## 기울임꼴·그림자

선택한 문구에서 Ctrl+I 또는 우측 기울임 버튼으로 기울임꼴을 켜고 끕니다. 문구 직접 편집 중에도 적용됩니다. 그림자를 켜면 색·진하기·흐림(0~40px)·거리(0~40px)를 조절할 수 있습니다. 효과는 PNG/JPG/GIF, 템플릿·JSON 및 실행 취소/다시 적용에 포함됩니다. 기울임과 그림자 여백을 저장 전 잘림 경고에 보수적으로 반영합니다. 텍스트 회전과 기울임꼴은 별개입니다.
